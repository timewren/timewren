# PWA- og favicon-ikoner

Alle filer her er genereret af `scripts/brand/generate-icons.mjs`
(`npm run brand:icons`) fra logo-geometrien i `docs/brand/logo/`
(se `docs/BRAND.md` → Logo og Ikoner pr. platform). Ret dem ikke i hånden.

- `favicon-16x16.png`: 16 px-udgave med tykkere visere
- `favicon-32x32.png`, `icon-72x72.png` … `icon-512x512.png`: hvid billet i granskov firkant
- `icon-maskable-192x192.png`, `icon-maskable-512x512.png`: fuld flade, billetten inden for safe zone
- `icon-180x180.png` (= `/apple-touch-icon.png`): fuld flade uden afrunding
- `badge-72x72.png`: monokrom hvid silhuet til push-notifikationer
