La aplicación móvil es una aplicación nativa que usa Expo. Se compila y se publica desde su propio repositorio, separado del servidor, e inicia sesión en la misma cuenta que la aplicación web.

Esta página trata de lo que tu servidor ofrece para ella. El servidor no decide cómo se introduce la dirección del servidor en la aplicación ni dónde se distribuye; eso lo cubre la documentación de la propia aplicación.

## Iniciar sesión

La aplicación usa el mismo inicio de sesión de dispositivo que la aplicación de escritorio: abre tu instancia en el navegador, inicias sesión y apruebas el dispositivo, y el navegador vuelve a la aplicación mediante el deep link `timetrack://auth/callback`. El token de acceso dura 30 días y se renueva con un token de refresco (180 días), así que rara vez tendrás que volver a iniciar sesión. La aplicación también puede usar los proveedores OAuth y Sign in with Apple que configures, consulta [Autenticación](/es/docs/configuration/authentication).

El servidor confía automáticamente en los esquemas de aplicación `timetrack://` y `timetrack.preview://`. No necesitas añadirlos a `TRUSTED_ORIGINS`.

Para Sign in with Apple nativo, define `APPLE_APP_BUNDLE_IDENTIFIER` con el bundle ID de la compilación de la aplicación que uses (por defecto `dk.timetrack.app`), junto con las demás variables de Apple.

## Notificaciones push

El servidor envía mensajes push a la aplicación a través de Expo. Para que las notificaciones funcionen, el servidor necesita un token de acceso de Expo:

```dotenv
EXPO_ACCESS_TOKEN=your-expo-access-token
```

Web Push para navegadores y la PWA es independiente y usa las claves VAPID. Ambos son opcionales.

## Versiones mínimas

Los operadores pueden exigir una compilación mínima con `MIN_CLIENT_VERSIONS`, por ejemplo `mobile=1.0.0+5`. La aplicación debe enviar un número de compilación numérico después del signo más para que esto pueda decidirse. Consulta [Aplicación de escritorio](/es/docs/apps/desktop) para ver el formato.

## Gestionar dispositivos

Los dispositivos con sesión iniciada aparecen como tokens en Ajustes, Integraciones, con el nombre del dispositivo y su último uso. Revoca uno para cerrar la sesión de ese dispositivo.
