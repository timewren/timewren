# Security Policy

Please do **not** open a public issue for security problems.

Email **security@timetrack.dk** with a description of the issue and its impact, steps to reproduce, and the version or commit you tested. You will get an acknowledgement within 3 working days. We aim to ship a fix for critical issues within 14 days and will credit you in the release notes unless you prefer to stay anonymous.

Out of scope: denial of service, social engineering, findings that require a compromised device, and issues caused by your own configuration. Only test against accounts and servers you own.

Security fixes land on `main`. Use the latest release.
