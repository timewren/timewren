# TimeWren brand kit

TimeWren's mark is a wren seen from the side. Its round body is a clock face,
and the cocked tail is the clock hand, pointing to one o'clock. The hand is cut
out of the body from the centre and carries on outside it as the tail.

Everything here is generated by `node scripts/brand/generate-timewren.mjs`.
Edit the script, not the files. All text is converted to paths, so no SVG
depends on an installed font.

## Colours

Use these five colours and no others.

| Name    | Hex       | Use                                                                                        |
| ------- | --------- | ------------------------------------------------------------------------------------------ |
| Ink     | `#1C2119` | Text and the mono mark. A green-black, not neutral black.                                  |
| Wren    | `#8A5A2B` | Feather brown. The mark's primary colour.                                                  |
| Thicket | `#3F5A3A` | Deep green. Surfaces in the dark variant, PWA theme colour.                                |
| Lichen  | `#E8EDE3` | Light, cool grey-green surface. Not cream.                                                 |
| Dawn    | `#E8B04B` | Golden accent. One element at a time, for example the hand in an active or animated state. |

## Files and when to use them

| File                                                | Use                                                                              |
| --------------------------------------------------- | -------------------------------------------------------------------------------- |
| `mark.svg`                                          | The mark in Wren. Default on white or Lichen.                                    |
| `mark-mono.svg`                                     | The mark in Ink, for one-colour print and stamps.                                |
| `mark-light.svg`                                    | The mark in Lichen, for Thicket or Ink surfaces.                                 |
| `wordmark.svg`                                      | Mark + "timewren" in Ink. Default logo on light surfaces.                        |
| `wordmark-light.svg`                                | Mark + "timewren" in Lichen, for dark surfaces.                                  |
| `favicon.svg`                                       | Browser tab icon. Wren on light tabs, Lichen in dark mode.                       |
| `favicon.ico`, `favicon-16.png`, `favicon-32.png`   | Fallback favicons (16/32/48).                                                    |
| `apple-touch-icon.png`                              | 180 px, full Lichen square (iOS adds the rounding).                              |
| `icon-192.png`, `icon-512.png`                      | PWA icons, rounded Lichen square.                                                |
| `icon-maskable-192.png`, `icon-maskable-512.png`    | Maskable PWA icons. The mark stays inside the 80 % safe zone.                    |
| `mark-64.png`                                       | The mark in emails (mail clients need a PNG).                                    |
| `og-image.png`                                      | 1200 × 630 share image.                                                          |
| `github-social-preview.png`                         | 1280 × 640, upload under the repository's Settings → Social preview.             |
| `readme-banner-light.svg`, `readme-banner-dark.svg` | 1280 × 320 README banner. Use both in a `<picture>` with `prefers-color-scheme`. |

## Rules

- Keep the mark flat: no gradients, shadows, glows, outlines or feather detail.
- Do not rotate the mark or move the hand. The tail always points to one o'clock.
- The mark sits to the left of the word, with the clock face at cap height.
  Do not stack them or put the mark on the right.
- The word is always lowercase: "timewren". In running text the product name
  is written "TimeWren".
- Use Dawn for one element only. The dark README banner uses it for the hand,
  so nothing else in that banner is Dawn.
- No terracotta, no cream backgrounds, no neon on black, no all-caps labels.
- Leave clear space around the mark of at least 1/6 of its height.
- Smallest size: 16 px for the mark, 96 px wide for the wordmark.

## Type

The wordmark is set in [Bricolage Grotesque](https://github.com/ateliertriay/bricolage)
at weight 680 with −0.02 em tracking. The variable font is in `fonts/` under
the SIL Open Font License (`fonts/OFL.txt`).
