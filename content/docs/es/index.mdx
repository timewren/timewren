TimeWren es un control de horas de código abierto para autónomos y equipos pequeños: clientes, proyectos, tareas, un temporizador, bonos de horas y facturación en una sola aplicación autoalojada. Funciona como una única imagen de Docker con PostgreSQL y un pequeño contenedor de cron. Una instancia autoalojada tiene todas las funciones abiertas, sin planes, límites de usuarios ni claves de licencia, y no envía telemetría.
