TimeWren is open-source time tracking for freelancers and small teams: clients, projects, tasks, a timer, prepaid hours and invoicing in one self-hosted app. It runs as one Docker image with PostgreSQL and a small cron container. A self-hosted instance has every feature open, with no plans, user limits or license keys, and sends no telemetry.

<Screenshot name="dashboard" alt="The TimeWren dashboard with today's time, active projects and prepaid balances" />

## Start here

- [Quickstart](/docs/quickstart): from an empty server to your first tracked hour in about ten minutes.
- [One-line install](/docs/install/quick): `curl -fsSL https://timewren.com/install.sh | bash` on a Linux server with Docker.
- [Use these docs with your LLM](/docs/llm): give the docs to Claude Code, Cursor, Codex or ChatGPT and let it install, upgrade or debug TimeWren for you.

## Install

| Method | Best for |
| --- | --- |
| [One-line install](/docs/install/quick) | A single Linux server with Docker. The fastest way. |
| [Docker Compose](/docs/install/docker-compose) | Full control over the Compose file and `.env`. |
| [Coolify](/docs/install/coolify) | You already run Coolify. |
| [Dokploy](/docs/install/dokploy) | You already run Dokploy. |
| [Railway](/docs/install/railway) | A managed platform, no server to maintain. |
| [Render](/docs/install/render) | A managed platform with a Blueprint. |
| [Kubernetes](/docs/install/kubernetes) | A Helm chart for an existing cluster. |
| [From source](/docs/install/from-source) | Building the image yourself or developing TimeWren. |
