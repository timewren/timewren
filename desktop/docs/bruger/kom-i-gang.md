# Kom i gang med TimeTrack Desktop

## Hvad er TimeTrack Desktop?

TimeTrack Desktop er en tidsregistreringsapp til din computer. Den sporer automatisk hvilke programmer du bruger, og hjælper dig med at omdanne det til tidsregistreringer på dine projekter.

Alt foregår lokalt på din computer -- dine aktivitetsdata forlader aldrig maskinen.

## Installation

### Windows

1. Download installationsfilen (.msi eller .exe) fra [timetrack.dk/desktop](https://timetrack.dk/desktop)
2. Kør installationsfilen og følg guiden
3. TimeTrack Desktop starter automatisk efter installation

Appen installeres i din brugermappe og kræver ingen administratorrettigheder.

### Første start

Når du åbner TimeTrack Desktop for første gang:

1. **Auto-tracking starter automatisk** -- appen registrerer i baggrunden hvilke vinduer du arbejder i
2. **Opret din første klient** -- gå til Klienter i sidebaren og klik "Ny klient"
3. **Opret et projekt** -- gå til Projekter og tilknyt det til din klient
4. **Gennemgå dine aktiviteter** -- åbn Tidslinjen for at se hvad appen har registreret

## Overblik over appen

### Sidebar-navigation

- **Timer**: Start/stop manuel timer og se dagens registreringer
- **Kalender**: Uge-, dag- og månedsvisning af dine tidsregistreringer
- **Tidslinje**: Se og bekræft automatisk registrerede aktiviteter
- **Klippekort**: Forudbetalte timepakker til klienter
- **Fakturaer**: Opret fakturaudkast fra tidsregistreringer
- **Klienter**: Administrer dine klienter
- **Projekter**: Administrer dine projekter
- **Indstillinger**: AI, tracking, sync og licensindstillinger

### Statusbar

Nederst i appen vises:
- Aktiv timer (projekt og tid)
- Sync-status (online/offline)
- Auto-tracking status

### Command palette

Tryk **Ctrl+K** for at åbne command palette -- en hurtig søgefunktion der lader dig navigere til alle sider og funktioner.

### System tray

TimeTrack Desktop minimerer til system tray (nederst til højre i proceslinjen). Højreklik på ikonet for at:
- Starte/stoppe timeren
- Åbne appen
- Afslutte appen
