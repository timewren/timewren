title: "Dinero"
description: "Conecta Dinero, el sistema de contabilidad danés, con TimeWren mediante OAuth de Visma Connect: importa contactos, exporta facturas y sincroniza pagos."
---

Dinero es un sistema de contabilidad danés. Como TimeWren es autoalojado, registras tu propia aplicación OAuth en Visma Connect y le das las credenciales al servidor. Después, cada usuario conecta su propia cuenta de Dinero con un clic.

> **Nota:** El acceso a la API requiere una organización Dinero Pro. Sin ella, la conexión falla con "No Dinero Pro organisation found".

## Qué hace

- Importa los contactos de Dinero como clientes (los contactos ya importados se omiten).
- Exporta un cliente a Dinero.
- Exporta una factura como borrador, contabilizada, o contabilizada y enviada. Eliges la cuenta de ingresos, las condiciones de pago y si va una línea por registro de horas o una línea combinada.
- Sincroniza de vuelta el estado del pago, de modo que las facturas pagadas se marcan como pagadas en TimeWren.

## Configuración del servidor

1. Registra una aplicación en Visma Connect (el portal de desarrolladores de la API pública de Dinero) y define esta URI de redirección, exactamente como está escrita:

   ```text
   https://timewren.example.com/api/integrations/dinero/callback
   ```

2. Añade las credenciales a `.env`:

   ```dotenv
   DINERO_CLIENT_ID=your-client-id
   DINERO_CLIENT_SECRET=your-client-secret
   # Only if the callback differs from NEXT_PUBLIC_APP_URL + /api/integrations/dinero/callback
   # DINERO_REDIRECT_URI=https://timewren.example.com/api/integrations/dinero/callback
   ```

3. Reinicia la aplicación.

El inicio de sesión usa los scopes `openid`, `dineropublicapi:read`, `dineropublicapi:write` y `offline_access`. El flujo hace un POST de vuelta a tu URL de callback desde otro sitio, así que tu instancia debe funcionar con HTTPS. Para probar en local con HTTP simple necesitas un túnel HTTPS.

`ENCRYPTION_KEY` debe estar definida, porque los tokens de OAuth se guardan cifrados. Consulta [Variables de entorno](/es/docs/configuration/environment).

Sin el ID de cliente, el botón Conectar redirige de vuelta con un error `dinero_not_configured`.

## Conectar como usuario

1. Abre Ajustes, Integraciones y elige Conectar con Dinero.
2. Inicia sesión en Visma Connect y aprueba el acceso. Si tienes acceso a varias organizaciones de Dinero, elige cuál conectar.
3. Elige la cuenta de ingresos por defecto (obligatoria para exportar facturas). Opcionalmente, asigna productos de Dinero para las horas y para los bonos de horas.
4. En Sistema de contabilidad por defecto, activa opcionalmente la sincronización automática del estado.

Los contactos se importan desde la página Sincronizar, dentro de Integraciones. Las facturas se exportan desde la propia factura.

Las conexiones antiguas hechas con una clave de API de Dinero siguen funcionando. La página de ajustes ofrece actualizar a OAuth.

## Sincronización y webhooks

El contenedor `cron` llama a `/api/cron/invoice-sync` cada 15 minutos para actualizar el estado de los pagos de los usuarios con la sincronización automática activada.

El endpoint `/api/webhooks/dinero` es opcional. Marca las facturas como pagadas con los eventos `InvoicePaid` y registra en el log los eventos de contabilización y envío. Las peticiones se verifican con una firma HMAC-SHA256 en la cabecera `x-dinero-signature`, usando un secreto que defines en el servidor y en Dinero:

```dotenv
DINERO_WEBHOOK_SECRET=a-long-random-string
```
